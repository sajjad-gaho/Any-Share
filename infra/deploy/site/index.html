Features

Everything you need to help on another computer

What the Windows app does today. Each capability is used only when the person at the remote computer grants it.

  • Remote screen viewing

    See the remote desktop in real time, fit it to your window, and choose a quality setting that suits your connection.

  • Mouse and keyboard control

    Click, type and use shortcuts on the remote computer, or join in view-only mode when that is all you need.

  • Connection requests and approval

    The remote computer is asked first and can allow full access, allow view only, or reject. Unanswered requests expire.

  • Clipboard and file transfer

    Copy and paste text between the two computers and send files during a session, when those permissions are granted.

  • Works across networks

    Computers connect directly when they can. When a network blocks that, traffic goes through an encrypted relay server instead.

  • Teams and roles

    Group computers in a team and give each member a role: owner, admin, operator or user. Roles decide who may connect and what they may do.

How it works

Connect two computers in three steps

  1. 1

    Download and install

    Install PBS AnyDesk on both Windows computers: the one you work from and the one you want to reach.

  2. 2

    Sign in and register

    Create an account, confirm your email, and sign in. Click Register this device to give the computer its 9-digit device ID.

  3. 3

    Request a connection

    Enter the other computer's Remote device ID, choose what you need, and send the request. The person there approves it.

To reach a computer that belongs to another account, both computers must be in the same team, and your role must allow the connection. A team owner or admin adds members and computers on the Team page.

Security & privacy

Access is never automatic

Downloading PBS AnyDesk does not give anyone access to your computer. A session starts only when every check below passes, and the person at the remote computer can always see it and end it.

  • Signed-in accounts and registered devices

    Both sides need an account. Each computer proves its identity with its own key, which never leaves that computer.

  • Permissions and approval

    Team roles decide who may connect. Approval is on by default, and the remote side can grant fewer permissions than were requested.

  • Optional access password

    A computer's owner can add a password that others must enter. Repeated wrong guesses are locked out.

  • Encrypted sessions

    Screen, input, clipboard and files travel over an encrypted WebRTC connection, also when it goes through the relay server.

FAQ

Frequently asked questions

What is PBS AnyDesk?

A Windows desktop app for remote access and remote support. You can view another computer's screen and, with permission, control it, share clipboard text and transfer files.

How do I download and install it?

Click Download for Windows and run pbs-anydesk-setup.exe. It needs 64-bit Windows. Because the installer is not code-signed yet, SmartScreen may warn you; compare the SHA-256 checksum first, then choose More info and Run anyway.

How do I connect two computers?

Install the app on both, sign in, and click Register this device on each. On your computer, enter the other computer's 9-digit Remote device ID and send a request. If the computers belong to different accounts, add both to the same team first.

Can I use it from a different network?

Yes. The two computers do not need to be on the same network. They connect directly when possible and through an encrypted relay server when a firewall or router blocks a direct connection. Both need internet access.

Does the remote computer need to approve a connection?

By default, yes. A window on the remote computer offers Allow, Allow view only or Reject, and a request expires if nobody answers. The computer's owner can turn approval off in Settings, but team roles and the optional access password still apply, and the session is always visible on the remote computer.

What should I do if a connection fails?

Check these in order:

  • Both computers are signed in and online.
  • The device ID is correct (9 digits).
  • Device not found usually means the computers are not in the same team, or your role does not allow the connection.
  • Someone was at the remote computer to approve the request before it expired.
  • A firewall allows the app's internet access. Then try again; the relay is used automatically when needed.
Are there any limitations I should know about?

Windows does not let the app control windows that run as administrator, the UAC prompt or the lock screen. Clipboard sharing is text only, and there is no audio and no unattended access.
